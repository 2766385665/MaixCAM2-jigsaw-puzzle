# MaixCAM 2 碎片识别第一版

## 功能

- 使用 MaixPy 官方 `camera.Camera` 读取摄像头；
- 使用 `image.image2cv` 转换为 OpenCV 图像；
- 将固定俯视的 A4 纸透视矫正到毫米比例；
- 识别上半区最多 4 块白色/亮色碎片；
- 使用 `approxPolyDP + fitLine + 相邻直线交点` 得到 3～5 边形；
- 显示每块的编号、边数、面积及各边厘米长度；
- 触摸 `FREEZE/RESUME` 冻结或恢复识别；
- 触摸 `SAVE` 保存原图、矫正图、二值图、标注图和 JSON 数据。

## 第一版使用条件

1. 推荐使用深色、无纹理、哑光 A4 纸作为工作底板。
2. 程序也支持棕色等较暗测试碎片放在白色A4纸上，会自动判断并反转前景极性。
3. MaixCAM 2 固定在 A4 正上方，不能倾斜太大。
4. 调整摄像头高度，使 A4 四角与屏幕中的绿色定位框重合。
5. 碎片放在 A4 上半区，不要互相接触，也不要越过黄色识别区域。
6. 拍摄时滑轨、电磁铁和碎片必须静止。

## 在 MaixVision 中运行

把以下文件复制或上传到 MaixCAM 2：

```text
maixcam2_piece_detector.py
```

在 MaixVision 中直接运行。程序不需要 `shapely`、`scipy` 或 `PyQt5`，只使用：

```text
maix
opencv-python（系统自带）
numpy（系统自带）
```

第一次运行时，先在 MaixCAM 2 的设置中执行“安装/更新运行库”。

## 屏幕操作

- `FREEZE`：冻结当前识别结果，终端同时输出 JSON 顶点数据。
- `RESUME`：继续实时识别。
- `SAVE`：将调试文件保存到：

```text
/root/puzzle_piece_debug
```

每次保存会生成：

```text
*_raw.jpg          原始相机图
*_rectified.jpg    A4透视矫正图
*_binary.png       分割二值图
*_result.jpg       多边形标注结果
*_result.json      顶点、边长、面积数据
```

## 重要参数

如果识别结果不正确，先查看保存的 `*_binary.png`。

```python
MIN_BRIGHT_THRESHOLD = 125
EPSILON_RATIO = 0.012
MIN_PIECE_AREA_CM2 = 2.5
MAX_PIECE_AREA_CM2 = 65.0
```

- 二值图中碎片缺失：降低 `MIN_BRIGHT_THRESHOLD`。
- 底板被识别成碎片：提高 `MIN_BRIGHT_THRESHOLD`，并使用更暗的底板。
- 一条直边被拆成两条：提高 `EPSILON_RATIO`，例如改为 `0.013`。
- 真实拐角被合并：降低 `EPSILON_RATIO`，例如改为 `0.007`。

## 当前边界

这一版用于验证“MaixCAM 2 能否稳定识别不同碎片”，暂未完成：

- 自动寻找任意位置的 A4 四角；
- 扑克牌接缝纹理匹配；
- 完整拼图搜索；
- 串口发送运动指令；
- 放置后的闭环纠偏。

只有在真实碎片重复识别测试通过后，才应继续接入拼图求解和滑轨控制。

## 2026-07-29 实拍修正

第一版在白色A4纸场景中生成的二值图是“白纸为白、碎片为黑”，而轮廓程序
只搜索白色前景，所以输出0块。修正版根据白色像素占比自动判断：

- 暗底板、亮碎片：保持原二值图；
- 白底板、暗碎片：自动反转二值图。

同时利用题目“每条真实边至少2 cm”的条件，自动删除由纸板毛刺或侧壁阴影
形成的小于1.75 cm的伪短边。用户提供的两张实拍原图均已识别为1块合法
四边形，且原来的暗底板4块混合测试仍然通过。

## v1.2 摄像头纵向安装

将MaixCAM 2相对原来的横向姿态顺时针旋转90°安装，使传感器的2560像素长边
沿着纵向A4纸的29.7 cm长边。程序采集仍为：

```text
2560×1440 @ 30 FPS
```

采集后自动顺时针旋转为：

```text
1440×2560
```

A4矫正图由原来的`840×1188（40 px/cm）`提高为：

```text
1260×1782（60 px/cm）
```

题目规定的2 cm最短边在矫正图中约为120像素。屏幕只显示缩小预览，轮廓
识别和顶点计算使用完整的1260×1782图像。

如果摄像头安装后屏幕预览上下颠倒，把代码中的：

```python
CAMERA_ROTATION = cv2.ROTATE_90_CLOCKWISE
```

改为：

```python
CAMERA_ROTATION = cv2.ROTATE_90_COUNTERCLOCKWISE
```

> 当前运行版本已经按实机性能反馈回退到v1.1。上述v1.2方案仅作为存档，
> 主程序不再执行90°旋转，A4矫正恢复为`840×1188（40 px/cm）`。

## PC侧软件回归

使用 200 组合成 Maix 相机画面测试了：

- 三角形、四边形、五边形随机混合；
- 暗背景和碎片亮度变化；
- 高斯模糊、像素噪声；
- 相机透视变换和二次重采样。

结果为 199/200 组的“碎片数量和每块边数”全部正确，其中一次为轮廓数量
筛选失败，未出现三角形、四边形、五边形相互误判。该结果只是软件回归，
不能替代 MaixCAM 2 实拍测试。
