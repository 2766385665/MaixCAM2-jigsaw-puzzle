# 一对多分段边 / T 形接缝求解（v2.1）

## 已实现内容

`maix_project/puzzle_solver.py` 不再只用“整条边已使用/未使用”的布尔状态。
每条多边形边现在使用 `0.0～1.0` 参数区间记录已接触部分，例如：

```text
长边：0.0 ----------------------------- 1.0
已拼：0.0 -------- 0.48
剩余：             0.48 ---------------- 1.0
```

因此第二块短边可以继续匹配 `0.48～1.0`，最终形成：

```text
短边 A + 短边 B  <=>  一条长边
```

搜索同时支持：

- 完整边对完整边；
- 短边贴到长边的前端；
- 短边贴到长边的后端；
- 已分割长边的剩余区间继续参与搜索；
- 长边先匹配一条短边，剩余部分以后再匹配；
- 分段闭合时使用独立累计误差容限；
- 根据剩余碎片边长提前剪掉不可能填满的分支。

## 安全判定

最终组合仍必须同时满足：

- 任意两块碎片的检测轮廓重叠面积不超过 `0.50 cm²`；
- 目标长短边符合赛题范围；
- 碎片总面积 / 最小外接矩形面积不低于 `0.92`。

程序不会因为加入 T 接缝就自动接受带明显空洞的近似组合。

当前实物测试采用宽松模式：完整度达到 `92.5%` 时提前接受唯一候选，
避免 MaixCAM 2 继续耗满搜索时间。
