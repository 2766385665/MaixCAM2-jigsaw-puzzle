## 当前启用版本

MaixVision 入口仍为：

```text

```

界面版本号为 `v3.0-global`。主程序现在调用

## 求解逻辑

新版不假设碎片保持正确朝向，也不固定 `theta=0`。每块碎片都同时求解：

```text
theta, tx, ty
```

求解过程为：

1. 为所有多边形边建立候选接缝；
2. 同时建立“一条完整边对一条完整边”和“一条长边对两条短边”的接缝族；
3. 枚举彼此不冲突的接缝拓扑；
4. 对候选拓扑执行全局刚体位姿优化；
5. 用矩形覆盖率、碎片重叠率、接缝残差共同评分；
6. 通过安全吸取点检查后生成滑轨搬运 JSON。

T 形接缝中的分叉点是长边上的虚拟点，不要求视觉多边形在该位置本身存在顶点。

## 当前容差

```text
完整边匹配：绝对误差 <= 0.55 cm，或相对误差 <= 10%
分段边匹配：累计误差 <= 0.75 cm，或相对误差 <= 12%
最终矩形覆盖率：>= 89%
碎片重叠率：<= 5.5%
接缝均方根残差：<= 0.50 cm
```

这些容差允许纸板裁剪、轮廓拟合和碎片间隙产生的误差，但最终仍必须整体接近矩形。容差不是简单放大旧的逐边 DFS 阈值，而是进入全局评分，因此单条边偶然近似不会直接形成错误答案。

## 防卡死

点击 `FREEZE` 后会先显示：

```text
Solving... max 10s
```

单次求解硬限制为 10 秒。全局求解没有通过质量门限时，会在剩余时间内调用旧版求解器回退；到达总时间限制后返回界面，不会无限遍历。

如板端性能测试仍明显超过可接受时间，可在
`maix_project/main.py` 中降低：

```python
SOLVER_MAX_SECONDS = 10.0
```

降低时间不会改变几何容差，但可能使较难题来不及完成。

## 回退到旧版

如果现场需要临时回退，只修改 `maix_project/main.py` 的导入：

```python
import puzzle_solver as puzzle_solver
```

不要删除 V3 文件，这样可以随时重新切换。
